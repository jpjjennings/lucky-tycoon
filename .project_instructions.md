# Lucky Tycoon — Project Instructions

## Overview
Browser-based Monopoly-inspired board game with a roguelite "Lucky Charms" system. Local pass-and-play, 2-4 players, same browser.

## Architecture
- **Engine** (`lib/engine/`): Pure TypeScript, UI-agnostic. types.ts, rng.ts (seeded PRNG), board-data.ts (40 spaces), charms-data.ts (15 charms, 4 synergies), event-deck.ts (6 events), event-bus.ts, reducer.ts, reducer-utils.ts, charm-effects.ts.
- **Store** (`lib/store.ts`): Zustand wrapping the reducer, localStorage autosave.
- **UI** (`app/_components/`): lobby-screen, game-board, board-grid, player-panel, action-bar, event-feed, charm-shop-modal, trade-modal, risk-modal, event-modal, bankruptcy-modal, synergy-notification, victory-screen.

## Visual Identity
- Dark casino theme, forced dark mode
- Accent colors: yellow-400 (#FFD700), emerald-400, purple accents
- Neon glow effects on important elements
- Font: DM Sans (body), Plus Jakarta Sans (display), JetBrains Mono (numbers)

## Key Rules
- No database needed — game state is client-side with localStorage persistence
- No AI opponents, no online multiplayer, no audio, no meta-progression — deferred to later sprints
- Engine must stay UI-agnostic for future reuse
- Original names/theme — NOT Monopoly branding
- Currency: "coins"
